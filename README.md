# 🎬 Movie Recommendation System

An AI-based movie recommendation system built using Python and Streamlit.

## 🚀 Live Demo

[Open AI Movie Recommendation](https://task-3-rishan-twzah8kswn5tsgbbg25bnd.streamlit.app/)

- 🎭 Genre-based recommendations
- 🌐 Language selection
- 😊 Mood-based recommendations
- 🎬 Movie posters
- 📱 Mobile-friendly interface
- 🌙 Dark theme

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Machine Learning
